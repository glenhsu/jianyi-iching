# 簡易 — 大道至簡 · 心誠則靈

**簡易** 是一個以 **高島易斷** 為基礎的線上易經占卜網頁，極簡三步驟起卦，單一 HTML 檔案即開即用。

🌐 **線上體驗**：https://glenhsu.github.io/jianyi-iching/簡易.html

---

## ✨ 特色

### 🎯 極簡占法
- **三步驟略筮法** — 上卦 → 下卦 → 動爻，保留高島古法精神，三步到位
- **雙重起卦** — 支援蓍草模擬（太極動畫）與快速輸入（下拉選單、二進位）
- **六十四卦完整資料庫** — 卦名、卦象、彖傳、象傳、爻辭，全部內建

### 🎨 設計亮點
- **宣紙古風** — 米色基底、朱紅點綴、楷體字型，古書卷質感
- **太極動畫** — CSS 太極圖旋轉、淡出、再現，營造莊嚴儀式感
- **響應式設計** — 桌面與手機皆可流暢使用

### 🛠️ 完整功能
- **問題輸入** — 記錄每次占卜意圖
- **三步引導** — 清楚標示起卦進度（求上卦→求下卦→求動爻）
- **完整解卦** — 本卦、變卦、動爻位置、高島解讀、彖傳、象傳
- **六十四卦瀏覽** — 8×8 網格瀏覽，點擊看詳情
- **占卜紀錄** — localStorage 儲存，時間倒序排列、支援刪除
- **CSV 匯出** — 一鍵匯出歷史紀錄
- **全離線** — 單一 HTML，無伺服器、無網路、無追蹤

## 🚀 使用方式

1. **下載** `簡易.html`
2. 用瀏覽器直接開啟（Chrome / Safari / Edge / Firefox 皆可）
3. 輸入問題，點擊「至誠無息，開始起卦」

或直接線上使用：https://glenhsu.github.io/jianyi-iching/簡易.html

## 📖 起卦方法

### 三步驟略筮法（推薦）
1. 輸入所占之事，點擊「至誠無息，開始起卦」
2. 太極開始旋轉 → 待 15 秒後點「上卦」→ 得出上卦
3. 點「下卦」→ 得出下卦
4. 點「動爻」→ 得出動爻，完成起卦

### 卦象輸入
- 上卦：下拉選單選擇（乾兌離震巽坎艮坤）
- 下卦：下拉選單選擇
- 動爻：選擇 1~6
- 亦可使用二進位輸入（如 `011` 兌、`100` 艮）

### 六爻硬幣法
- 準備 6 枚 1 元硬幣 + 1 枚六面骰
- 擲骰決定動爻後，以硬幣陰陽得出上下卦
- 適合多人或戶外場合快速起卦

## 📜 關於高島易斷

高島嘉右衛門（1832–1914）為日本明治時代易學大師，其《高島易斷》以「略筮法」聞名。本系統採用其斷卦邏輯，結合現代網頁技術，讓千年易學智慧在數位時代延續。
